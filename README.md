# ZELAR

**Slogan:** Cuidar do que é de todos.

A ZELAR é uma iniciativa de tecnologia cívica orientada para aproximar cidadãos, equipas de inspeção e entidades públicas na identificação, comunicação, acompanhamento e resolução de ocorrências no espaço público.

## Estado do projeto

- Identidade visual: conceito V1.0 aprovado.
- Manual de identidade visual: documento conceptual V1.0 em desenvolvimento.
- Plataforma e implementação técnica: não iniciadas nesta etapa.

## Repositório oficial e regra de preservação

Este repositório é a fonte oficial de documentação e artefactos do projeto ZELAR.

**Todo o trabalho produzido e aprovado no âmbito do projeto deve ser registado neste repositório**, incluindo decisões, requisitos, documentos, especificações, versões, auditorias e artefactos aplicáveis.

Regras de trabalho:
1. Consultar o estado atual do repositório antes de alterar ou criar conteúdo.
2. Registar decisões e entregáveis relevantes em ficheiros versionados.
3. Preservar versões aprovadas; não substituir silenciosamente decisões ou artefactos anteriores.
4. Identificar claramente conteúdo conceptual, conteúdo em desenvolvimento e conteúdo aprovado.
5. Não declarar uma tarefa concluída sem verificar o respetivo registo no repositório.
6. Não avançar para etapas posteriores sem autorização expressa quando existir uma aprovação por fases.
7. Manter histórico através de commits claros e descritivos.
